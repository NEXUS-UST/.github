# NEXUS-UST — organisation profile

This repository holds the organisation profile for [@NEXUS-UST](https://github.com/NEXUS-UST).

The file that actually renders on the organisation page is **[`profile/README.md`](profile/README.md)** —
GitHub reads that specific path, not this one. Edit that file to change what visitors see.

## What lives in this organisation

- **[ClubPage](https://github.com/NEXUS-UST/ClubPage)** — NEXUS at the University of St. Thomas — the club website at ustnexus.club: events, workshops, membership and the Buildfest program.
- **[build-workshop](https://github.com/NEXUS-UST/build-workshop)** — NEXUS Workshop: Build Your Personal Website — workshop site and materials at build.ustnexus.club for University of St. Thomas students.
- **[USTMCC](https://github.com/NEXUS-UST/USTMCC)** — UST Management Consulting Club — the club website at management-consulting.club.
- **[nexus-forum](https://github.com/NEXUS-UST/nexus-forum)** *(archived)* — NEXUS community forum. forum.ustnexus.club no longer resolves.
- **[InternalSite](https://github.com/NEXUS-UST/InternalSite)** *(archived)* — NEXUS internal members site. University of St. Thomas club work, no longer maintained.
- **[Buildfest](https://github.com/NEXUS-UST/Buildfest)** *(archived)* — NEXUS Buildfest event site (2026). University of St. Thomas club work, no longer maintained.

## Conventions

- Repository names are lowercase-kebab unless the name is a domain or a proper noun.
- Every live repository carries a description, topics, and a Website link where one exists.
- Archived repositories are prefixed `⛔️ ARCHIVED` and carry a banner at the top of their README.
- Secret scanning and push protection are enabled by default for new repositories here.
